# Kitaly homepage and Stock alignment

## Scope and authority
The user requested alignment with the existing Stock page and a livelier menu, then explicitly authorized recreating the deleted local-home folder. The supplied crest and the Stock page's typography, brass details and warm surfaces are visual authority. Homepage remains a standalone local preview.

- Club green #244d3e; hover green #19392d; brass #88672f; navigation highlight #e9ce90; rule #d3c5ae.
- Display Cormorant Garamond 500/600; body Libre Franklin 400–700. Fonts downloaded and self hosted.
- Hero desktop max 82px, mobile 57px. Section title 45px desktop / 38px mobile. Functional text minimum 11px. Body 13–14px.
- Content max width 1440px; desktop gutters 48px, tablet 32px, mobile 20px. Breakpoints 1100/850/650px.

## Composition
Compact centered crest replaces the previous oversized text masthead. Green navigation rail with brass active underline; mobile expands to a vertical link list. Category descriptions remain three editorial columns on desktop and stack on phones. Four product columns become two. Source image is displayed through CSS crop windows, labelled illustrative. Founder section splits on desktop and stacks on phones. Footer repeats the crest, cream surface and brass rules of the Stock page.

## Behaviors and limits
Category/era filters, empty and reset states, product enquiry dialog, empty bag dialog, mobile navigation, Instagram and email links work. Main navigation links to isolated local Stock preview at port 5002. No checkout. Founder photo and full policies await content. Original supplied copy, seasons, grades and £55 price retained.
